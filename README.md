# Frontend Playground - React Component Lab

A collection of interactive React components and responsive layouts developed to practice state lifting, modular hooks, props drilling solutions, and modern CSS integration.

## Features & Components

- **Dynamic Data Cards**: Reusable card components with interactive actions and hover states.
- **Responsive Grid**: Adaptive layout scaling effortlessly from single-column mobile to multi-column desktop.
- **State Management**: Clean React `useState` and `useEffect` patterns for stateful UI flow.

## Tech Stack

- **Core**: React 18, Vite
- **Styling**: Modern CSS3, Flexbox & Grid
- **Linting**: ESLint configured with modern rules
